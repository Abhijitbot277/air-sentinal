# AIR SENTINAL — Demo Script

## 60-second demonstration

### 1. Identify the worker

Show the worker profile and wristband ID on the dashboard.

> “Each wearable is associated with a unique worker ID so that an event can be linked to the correct worker.”

### 2. Show normal state

Point to the monitoring panel.

> “The system starts in a normal state and continuously monitors the incoming sensing response.”

### 3. Trigger the demonstration event

Click **Simulate H₂S Exposure**.

> “For this software demonstration, we are simulating an exposure event. This lets us demonstrate the complete data and alert workflow without generating hazardous H₂S.”

### 4. Explain the alert

Show the alert card and event history.

> “The event is associated with the worker ID, recorded with a timestamp, and displayed as an alert on the central monitoring dashboard.”

### 5. Show health and attendance

Point to the worker information card.

> “The same worker record can be extended with attendance and optional health information. The values shown here are demonstration data.”

### 6. State the research boundary

> “Our next engineering step is controlled experimental validation of the passive colorimetric sensing response, followed by image analysis and measured classification performance.”

## Key message

**Detect. Protect. Empower.**

The goal is worker-level awareness and traceability, not simply detecting that a hazardous condition exists somewhere in a plant.
