- [x] Monitoring dashboard

- [x] Demo health/attendance view

## Phase 2 — Wearable prototype

- [ ] Build wristband enclosure
- [ ] Add unique Worker ID
- [ ] Integrate passive colorimetric sensing element

## Phase 3 — Data and communication

- [ ] Capture response data
- [ ] Store timestamp + Worker ID + sensor response
- [ ] Implement wireless data transfer
- [ ] Connect physical data source to dashboard

## Phase 4 — Experimental validation

- [ ] Measure repeatability
- [ ] Measure response and recovery behavior
- [ ] Test lighting and viewing-geometry effects
- [ ] Investigate temperature/humidity effects
- [ ] Investigate interference/selectivity
- [ ] Establish calibration methodology
- [ ] Quantify detection performance from measured data

## Phase 5 — Intelligent analysis

- [ ] Build a measured dataset
- [ ] Extract color/image features
- [ ] Compare suitable classification approaches
- [ ] Evaluate using held-out experimental data
- [ ] Document limitations and failure cases

## Important

Accuracy, detection limits, dataset size and classification metrics should only be added after they are experimentally measured and reproducible.
