# AIR SENTINAL

Smart wearable safety system for worker-level H₂S exposure monitoring, worker identification, alerts, and health tracking.

## SIH26118 — Smart Automation

AIR SENTINAL is designed for refinery, petrochemical, oil & gas, and maintenance environments where hydrogen sulfide (H₂S) exposure can create serious worker-safety risks.

### Core concept

**WORKER → SMART WRISTBAND → WIRELESS → CONTROL COMPUTER → ALERT / HEALTH / ATTENDANCE**

The wearable is intended to combine passive colorimetric H₂S sensing, Worker ID, wireless transmission, exposure alerts, and worker health/attendance records.

### Current demonstration

This repository currently contains documentation and a browser-based software demonstration of the monitoring workflow. Exposure events and readings used in the demo are simulated and are **not presented as experimentally validated sensor measurements**.

### Planned engineering work

- Wristband sensing prototype
- Controlled H₂S colorimetric-response experiments
- Image/color analysis for sensor interpretation
- Wireless communication
- Central monitoring dashboard
- Exposure history and worker-level records
- Optional health/attendance integration

### Safety and validation

AIR SENTINAL is a prototype/research project. Sensor performance, detection limits, response time, selectivity, and classification accuracy must be experimentally measured before making performance claims or using the system for real-world safety decisions.
