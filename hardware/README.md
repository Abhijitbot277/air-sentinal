# Hardware

This folder contains the planned physical prototype structure for AIR SENTINAL.

## Current state

The physical sensing hardware is under development. The repository currently documents the intended architecture and component roles; it does not claim a validated H₂S detector.

## Suggested structure

```text
hardware/
├── README.md
├── components.md
├── circuit/
│   └── README.md
└── firmware/
    └── README.md
```

Future commits should add the actual circuit, firmware and test documentation as those parts are built and verified.
