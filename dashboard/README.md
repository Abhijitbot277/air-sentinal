# AIR SENTINAL Dashboard Demo

A zero-build browser demo for the AIR SENTINAL SIH26118 prototype.

## Run

Open `index.html` in any modern browser.

## Demonstration flow

1. Worker **AS-024** is shown as connected.
2. Click **Simulate H₂S Exposure**.
3. The dashboard changes to an alert state.
4. The worker ID is associated with the event.
5. The event is added to the exposure history.
6. Click **Clear Alert** to return to the safe state.

All exposure responses and health values in this dashboard are simulated demonstration data. They are not validated sensor measurements and must not be used for real-world safety decisions.
